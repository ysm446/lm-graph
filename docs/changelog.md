## 0.1.0

### 初期アプリ基盤

- Electron + React + React Flow + SQLite によるローカル LLM 向けノードグラフアプリを実装した。
- ローカル `llama.cpp` OpenAI 互換サーバーを起動・停止し、`text` ノードにストリーミング生成できるようにした。
- プロジェクト作成、リネーム、複製、削除、明示的な保存、未保存変更の扱いを追加した。
- アプリデータの保存先を `data/` 配下に整理し、プロジェクトごとのカメラビューポートも保存するようにした。
- UI 設定を JSON に永続化し、サイドバー幅、ミニマップ、スナップ to グリッド、エッジ形状、テキストサイズなどを保持できるようにした。

### ノードと接続

- `text` / `context` / `instruction` ノードを追加し、型付きハンドルで接続できるようにした。
- `context` / `instruction` ノードに Global / Local スコープを追加し、上流 `text` ノードからグローバル文脈を伝播できるようにした。
- `image` ノードを追加し、画像の読み込み、差し替え、複製、プレビュー表示、`text` ノードへの画像入力に対応した。
- Vision 対応モデルでは `mmproj-*.gguf` を検出し、画像データを multipart の `image_url` として送信できるようにした。
- エッジ選択色、ノード種別ごとの出力ハンドル色、Local ノードの破線表示、入力ラベルとハンドル位置を調整した。
- エッジのサイクル防止、厳密なハンドル種別チェック、複数ノード選択・コピー・貼り付け、貼り付け時の上流ワイヤ保持に対応した。

### 生成とプロンプト

- 上流ノードをたどって `instruction` を system prompt、`context` / `text` / `image` 情報を user message に組み立てる生成フローを実装した。
- Target Node が user message の末尾に来るようにプロンプト順序を調整し、生成意図が伝わりやすくした。
- `Generate Downstream` を追加し、下流ノードを順番に生成できるようにした。
- 生成キューと生成中ノードの発光表示を追加した。
- 生成中のノード内容更新を完了時まで遅延し、React Flow 更新ループを減らしてキャンバス性能を改善した。
- 最後に使ったモデルを記憶し、生成時に自動ロードできるようにした。
- モデル未ロード時の校正リクエスト抑止、生成開始フロー、stale closure による生成ボタン不発や下流生成スキップを修正した。

### 編集・校正・詳細パネル

- 詳細パネルに読み取りと生成操作を集約し、レスポンシブな高さ、タイトル行のアクション、ダブルクリック編集、保存 UI を整えた。
- ノード本文プレビューで改行を保持し、260 文字制限を撤廃した。
- ノード内容のスクロール、編集時の textarea 幅、テキスト選択コピー、`Ctrl+C` の扱いを改善した。
- 選択範囲の校正機能を追加し、`Light` / `Standard` / `Aggressive` / `Custom` プリセット、編集可能な system prompt、詳細パネル内校正に対応した。
- キーボードショートカット、インラインリネーム、削除アクション、保存アイコン、dirty indicator を整備した。

### UI と操作性

- ヘッダー、左右サイドバー、インスペクター、ミニマップ、ダイアログ、コンテキストメニュー、モデルロードモーダルの見た目と操作感を継続的に改善した。
- 左右ペインの表示切り替え、サイドバーのリサイズ、プロジェクト一覧内保存ボタン、ズームアウト時の固定サイズタイトル表示を追加した。
- React Flow 標準コントロールを非表示にし、キャンバスのドット、ノードカード、選択エッジ、コンパクトなメニュー表示を調整した。
- CPU / RAM / GPU / VRAM を表示するシステムリソースモニターをキャンバスに追加し、レイアウトを整理した。
- Electron 起動時のちらつき、runtime path、アプリケーションアイコン、モデル停止処理、llama port 管理を安定化した。
