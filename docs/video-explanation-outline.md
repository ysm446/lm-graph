## 一言で説明するなら

LM Graph は、ストーリーのフローチャートを作るように、文章生成の材料と指示を視覚的に整理できるローカル LLM アプリです。

別の言い方をすると、ストーリーや文章生成のための自然言語プログラムを、フローチャートとして編集するアプリです。

## もう少し詳しい説明

通常のチャットでは、過去の会話や設定が一本の流れにまとまってしまい、どの情報がどの生成に影響しているのか分かりにくくなることがあります。

LM Graph では、本文、世界観、キャラクター設定、今回の展開指示、参考画像などをそれぞれノードとして置き、必要なものだけを線でつなぎます。

これにより、「この設定を使ってこの場面を書く」「この展開案から別ルートを試す」「この文章を元に続きを生成する」といった作業を、ストーリーの分岐図や制作メモのように扱えます。

## 思想としての説明

LLM は、言葉で状態空間を誘導する機械だと考えられます。

プロンプトを書くことは、通常のプログラムのように命令を一行ずつ厳密に実行させる作業とは少し違います。むしろ、意味の重力場を作って、生成される文章をそちらへ曲げる作業に近いです。

たとえば、世界観、キャラクター設定、文体、今回の展開指示を言葉で与えると、LLM が出しうる文章の範囲がその方向へ寄っていきます。プロンプトは、その生成の向きや強さを調整するための自然言語プログラムのように扱えます。

LM Graph は、その自然言語プログラムをノードと線で見える形にします。`context` は参照情報や設定、`instruction` は振る舞いのルール、`text` は本文や途中結果、エッジはどの情報をどの生成へ渡すかを表します。

そのため LM Graph では、文章生成を一回きりのチャットではなく、「どの意味を置き、どの方向へ生成を曲げるか」を編集する作業として扱えます。

## 動画の導入案

こんにちは。今回は、ローカル LLM を使ってストーリー制作や文章生成の流れを整理できるアプリ、LM Graph を紹介します。

このアプリは、簡単に言うと「ストーリーのフローチャートを作るアプリ」です。ただし、単に図を描くだけではなく、ノードに書いた本文や設定、指示をつないで、そのまま LLM に続きを生成させることができます。

チャット形式の生成では、設定や指示が長くなるほど管理が大変になります。LM Graph では、それらをグラフとして見える形に分けておけるので、どの情報を使って何を生成したのかを後から追いやすくなります。

少し抽象的に言うと、LLM は言葉で状態空間を誘導する機械です。プロンプトは、意味の重力場を作って生成を狙った方向へ曲げるものです。LM Graph は、その自然言語プログラムをフローチャートとして編集できるようにするアプリです。

## 見せたいポイント

- 文章や設定をノードとしてキャンバス上に置ける。
- ノード同士を線でつなぐことで、生成に使う情報の流れを作れる。
- ストーリーの分岐、別案、続き生成を視覚的に整理できる。
- `context` ノードで世界観や背景情報を持たせられる。
- `instruction` ノードで文体や今回の生成指示を指定できる。
- `text` ノードで本文や生成結果を扱える。
- 画像ノードを使うと、Vision 対応モデルでは画像も入力として使える。
- ローカルの `llama.cpp` サーバーを使うため、プロジェクトや生成素材を手元で扱える。

## デモ構成案

1. 空のキャンバスを見せる。
2. ストーリーの本文ノードを作る。
3. 世界観やキャラクター設定を `context` ノードとして追加する。
4. 「この場面の続きを書く」「緊張感のある文体にする」などの `instruction` ノードを追加する。
5. ノードをつないで、生成に使う情報の流れを作る。
6. `text` ノードで続きを生成する。
7. 生成結果から別ルートのノードを作り、分岐や試行錯誤ができることを見せる。
8. 必要に応じて、詳細パネルで文章を編集・校正する。

## ナレーション骨組み

### 1. アプリの概要

LM Graph は、ローカル LLM を使った文章生成の流れを、ノードグラフとして組み立てるアプリです。

ストーリー制作で言えば、本文、設定、キャラクター情報、展開指示、別案などをそれぞれカードのように置いて、それらを線でつなぎながら制作できます。

言い換えると、ストーリーや文章生成のための自然言語プログラムを、フローチャートとして編集するアプリです。

### 2. チャットとの違い

チャット形式では、会話が長くなるほど「今どの設定が効いているのか」「この生成は何を元にしたのか」が分かりにくくなります。

LM Graph では、情報をノードとして分けておけるため、参照したい設定や指示だけを選んで生成できます。

LLM への指示は、厳密な命令列というより、生成を特定の方向へ導くための意味の配置です。LM Graph では、その意味の配置をノードグラフとして見ながら編集できます。

### 3. ストーリー制作での使い方

たとえば、最初に世界観の説明を `context` として置きます。次にキャラクター設定、現在のシーン、今回の展開指示を追加します。

それらを本文ノードにつなぐと、LLM は接続された情報をもとに続きを生成します。

生成結果が気に入ったら次のノードにつなげて続けられますし、別の展開を試したい場合は分岐を作って比較できます。

### 4. ローカルで動くこと

LM Graph は、ローカルの `llama.cpp` サーバーと連携して動作します。モデルやプロジェクト、画像などを手元の環境で扱えるため、制作途中の素材をローカルに置いたまま作業できます。

### 5. 締め

LM Graph は、文章生成を一回きりのチャットではなく、見える形で積み上げていくためのアプリです。

ストーリーの構成、分岐、設定管理、続きを生成する流れを、ひとつのキャンバス上で整理したいときに使えます。
