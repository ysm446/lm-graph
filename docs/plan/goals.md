# LM Graph の目標

作成日時: 2026-06-07 21:59
更新日時: 2026-06-07 21:59

## プロジェクトの目的

LM Graph は、ローカル LLM を使った文章生成・編集ワークフローを、ノードグラフとして視覚的に組み立てる Windows 向けデスクトップアプリです。

単発のチャットではなく、素材、文脈、指示、生成結果をノードとして残し、接続関係によって「どの情報を使って何を生成したか」を扱えるようにすることを目的にします。

## 完成形

- `text` / `context` / `instruction` / `image` ノードを使って、生成に必要な情報をキャンバス上で整理できる。
- `text` ノードを起点に、上流ノードの内容を適切な順序でプロンプトへ組み立て、ローカル `llama.cpp` サーバーで生成できる。
- Global / Local スコープによって、広く伝播する文脈と特定ノードだけに効く文脈を使い分けられる。
- Vision 対応モデルでは画像ノードを実画像入力として扱い、非対応モデルでは画像メタ情報だけを安全に扱える。
- プロジェクト、UI 設定、ノード位置、ビューポート、画像アセットをローカルに保存し、継続作業できる。
- 詳細パネル、校正、ショートカット、複製、下流生成などにより、文章編集の反復作業をスムーズに行える。

## 重視する価値

- ローカル完結: モデル、プロジェクト、画像、設定をユーザーのローカル環境で扱う。
- 見通しのよさ: 文脈や指示がどの生成に影響するかを、グラフ構造で確認できる。
- 反復しやすさ: 生成、校正、編集、保存、再生成を短い操作で回せる。
- 破綻しにくさ: 型付き接続、サイクル防止、保存確認、モデル状態管理により、作業中の事故を減らす。
- 実用的な軽さ: UI の装飾より、キャンバス操作、詳細編集、モデル操作、リソース確認の使いやすさを優先する。

## 非目標

- クラウドモデルプロバイダーの統合。
- 複数ユーザーによる同期編集。
- リモートストレージを前提にしたプロジェクト管理。
- 汎用ワークフローエンジンや複雑な自動化基盤への拡張。
- モデル本体や `llama-server.exe` のリポジトリ同梱。
